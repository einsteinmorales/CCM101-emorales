# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud platform that provides computing, storage, databases, networking, AI, and data analytics services.

## Global Infrastructure

GCP uses a global network of **regions and zones** connected through Google's private network infrastructure.

## Cloud Management Console

The **Google Cloud Console** is a web-based interface used to create, manage, monitor, and configure Google Cloud resources.

## Four Core Services

1. **Compute Engine** – Virtual machines for running applications.
2. **Cloud Storage** – Object storage for files and data.
3. **Cloud SQL** – Managed relational database service.
4. **Cloud Functions** – Serverless service for running code.

## Three Advantages

* **High performance** – Uses Google's global network.
* **Scalable** – Resources can be adjusted as needed.
* **Strong data and AI tools** – Provides powerful analytics and machine learning services.

## Typical Enterprise Use Cases

* Website and application hosting
* Data storage and backup
* Big data analytics
* Artificial intelligence and machine learning
* Database management
