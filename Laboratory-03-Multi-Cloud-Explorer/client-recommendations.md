# Checkpoint 4

# Cloud Platform Recommendations

## Client A – Startup Company

**Recommended Platform: AWS**

AWS is a good choice because it offers flexible and scalable services that can support a growing startup. The company can start with a small amount of resources and increase them as the application grows. AWS also provides many services with pay-as-you-go pricing. The startup could use **Amazon EC2, Amazon S3, and AWS Lambda**.

## Client B – University

**Recommended Platform: Microsoft Azure**

Microsoft Azure is the best choice because the university already uses Microsoft technologies. Azure integrates well with **Windows Server, Microsoft 365, and Active Directory/Entra ID**. This can make the migration to the cloud easier and allow the university to continue using familiar Microsoft tools. The university could use **Azure Virtual Machines, Azure Active Directory/Entra ID, and Azure Blob Storage**.

## Client C – AI Research Company

**Recommended Platform: Google Cloud Platform (GCP)**

GCP is a strong choice for an AI and Machine Learning research company because of its powerful AI, data, and computing services. It provides tools and infrastructure designed for developing and running machine learning workloads. GCP can also provide high-performance computing resources when needed. The company could use **Compute Engine, Vertex AI, and Cloud Storage**.

## Client D – Global E-Commerce Company

**Recommended Platform: AWS**

AWS is suitable for a global e-commerce company because it provides a large worldwide infrastructure and highly scalable services. The company can deploy applications across multiple regions and automatically adjust resources based on customer demand. AWS also provides services for databases, storage, networking, and content delivery. The company could use **Amazon EC2, Amazon S3, and Amazon CloudFront**.
