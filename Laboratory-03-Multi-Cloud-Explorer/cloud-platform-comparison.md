## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

**AWS** offers the broadest range of cloud services. It provides many options for computing, storage, databases, networking, security, analytics, and AI.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** provides the best integration with Microsoft technologies. It works closely with products such as Windows Server, Microsoft 365, and Active Directory/Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud Platform (GCP)** is particularly strong in artificial intelligence, machine learning, and Kubernetes. Google also created Kubernetes, which contributes to its strong container and Kubernetes ecosystem.

### 4. Which cloud platform would you personally choose and why?

I would personally choose **AWS** because it offers a wide range of services and has a large global infrastructure. It is also flexible and suitable for many different types of applications and organizations.
