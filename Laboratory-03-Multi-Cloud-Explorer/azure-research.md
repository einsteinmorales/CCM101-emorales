# Azure Research

## Brief Overview

Microsoft Azure is a cloud platform that provides computing, storage, databases, networking, AI, and security services.

## Global Infrastructure

Azure has a global network of **regions and data centers** that help organizations deploy applications closer to their users.

## Cloud Management Console

The **Azure Portal** is a web-based interface used to create, manage, monitor, and configure Azure resources.

## Four Core Services

1. **Azure Virtual Machines** – Cloud-based virtual computers.
2. **Azure Blob Storage** – Storage for files and unstructured data.
3. **Azure SQL Database** – Managed relational database service.
4. **Azure Functions** – Serverless platform for running code.

## Three Advantages

* **Scalable** – Resources can be adjusted based on demand.
* **Global** – Available in many regions worldwide.
* **Microsoft integration** – Works well with Microsoft products and services.

## Typical Enterprise Use Cases

* Application hosting
* Data storage and backup
* Database management
* AI and analytics
* Business application development
