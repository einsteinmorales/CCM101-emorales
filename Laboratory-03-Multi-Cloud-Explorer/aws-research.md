# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud platform that provides computing, storage, databases, networking, security, and other cloud services.

## Global Infrastructure

AWS has a worldwide infrastructure made up of **Regions and Availability Zones**. This allows businesses to deploy applications in different locations and improve reliability.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to create, configure, monitor, and manage AWS resources and services.

## Four Core Services

1. **Amazon EC2** – Virtual servers for running applications.
2. **Amazon S3** – Object storage for files and data.
3. **Amazon RDS** – Managed relational databases.
4. **AWS Lambda** – Runs code without managing servers.

## Three Advantages

* **Scalable** – Resources can easily be increased or decreased.
* **Global** – Services are available across many geographic locations.
* **Wide range of services** – Supports computing, storage, databases, AI, security, and more.

## Typical Enterprise Use Cases

* Website and application hosting
* Data storage and backup
* Database management
* Disaster recovery
* Data analytics and AI
