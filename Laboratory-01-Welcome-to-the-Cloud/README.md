# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to the basic environment and responsibilities of a Cloud Infrastructure Engineer. As a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies, I was tasked with setting up a Linux environment using the KillerCoda Playground, exploring the Linux operating system, gathering system information, organizing files, and creating a professional GitHub portfolio.

The activity provided hands-on experience with Linux commands, user management, file organization, Markdown documentation, and version-controlled project management using GitHub.

## Objectives

The objectives of this laboratory activity are to:

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Create and manage a Linux user account.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.
- Practice proper documentation and version control.

## Activities Performed

During this laboratory activity, I performed the following tasks:

1. Launched an Ubuntu 24.04 Linux Playground using KillerCoda.
2. Verified that the Linux terminal was functioning properly.
3. Created a new Linux user named `emorales`.
4. Configured the user with a home directory, Bash shell, and sudo privileges.
5. Logged in to the newly created user account.
6. Checked the current username, working directory, and hostname.
7. Investigated the Linux distribution and kernel version.
8. Checked the CPU information and available memory.
9. Checked the available disk space.
10. Created and organized the required directories and Markdown files.
11. Created a public GitHub repository named `CCM101-emorales`.
12. Organized the laboratory documentation and screenshots in the repository.

## Linux Commands Used

| Command | Purpose |
|---|---|
| `sudo adduser emorales` | Creates a new Linux user |
| `sudo usermod -aG sudo emorales` | Adds the user to the sudo group |
| `su - emorales` | Logs in as the new user |
| `whoami` | Displays the current username |
| `pwd` | Displays the current working directory |
| `hostname` | Displays the hostname |
| `cat /etc/os-release` | Displays Linux distribution information |
| `uname -r` | Displays the kernel version |
| `lscpu` | Displays CPU information |
| `free -h` | Displays memory information |
| `df -h` | Displays disk space information |
| `mkdir` | Creates directories |
| `touch` | Creates files |
| `cat` | Displays file contents |
| `nano` | Creates and edits text files |
| `tree` | Displays the directory structure |
